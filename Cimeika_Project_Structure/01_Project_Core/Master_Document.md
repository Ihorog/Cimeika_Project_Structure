# Cimeika Master Document

## Загальне призначення та функціональність

Cimeika — це інтегрована багатофункціональна платформа, створена для оптимізації обміну даними, залучення користувачів і керування різноманітними життєвими процесами. Головна мета системи – ефективно використовувати час користувача як ключовий ресурс, автоматизувати рутинні процеси за допомогою алгоритмів Ci (central intelligence) та забезпечити прозорість, зручність і безпеку для всіх учасників платформи.

## Ключова особливість - Ci-асистент

Ci є центральним агентом системи, через який користувачі взаємодіють з усіма функціями Cimeika. Він забезпечує структурований обмін даними, виступає посередником між користувачем та різними модулями і водночас виконує роль контролера.

### Ролі Ci:
- **Асистент**: відповідає на запити та виконує команди
- **Навігатор**: спрощує перемикання між розділами
- **Контекстуальний помічник**: пропонує інструменти залежно від ситуації

## Система персонажів

Всього проект має п'ять персонажів:
1. **Ci** - головний координатор з власним образом
2. **ПоДія** - планування та організація подій
3. **Настрій** - відстеження настрою і ментальне здоров'я
4. **Маля** - розвиток дитячої творчості
5. **Казкар** - [потребує специфікації]

## Технічна архітектура

### Backend
- Python 3.9 + Flask + Gunicorn
- REST API з OpenAPI специфікацією
- Docker контейнеризація (порт 8000)

### Frontend  
- SPA (Single Page Application)
- Динамічна навігація через scripts.js
- Інтерактивні форми та чат-інтерфейс

### Зовнішні інтеграції
- OpenAI API (Ci-асистент)
- Google Calendar API (синхронізація подій)
- Telegram Bot API (мобільний доступ)
- Dropbox API (медіа зберігання)
- OpenWeatherMap API (погодні дані)
- FreeAstrologyAPI (гороскопи)
- Health API (показники здоров'я)

## Компоненти системи

### Календар
Центральний інструмент для керування всіма подіями, завданнями та нагадуваннями. Синхронізується з Google Calendar.

### Галерея
Централізоване медіа-сховище для:
- Фотографії сім'ї (категорія "Family")
- Креативні роботи дітей ("Creativity") 
- Зображення подій ("Events")
