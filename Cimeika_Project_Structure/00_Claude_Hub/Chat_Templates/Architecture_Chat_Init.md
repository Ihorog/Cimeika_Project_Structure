# Стартовий контекст для архітектурного чату

Привіт! Це архітектурний чат для проекту Cimeika.

## Контекст
Читай Master_Context в 00_Claude_Hub для повного розуміння проекту.

## Фокус цього чату
- Архітектурні рішення та паттерни
- Взаємодія між модулями (Ci, ПоДія, Настрій, Маля, Казкар)
- Scalability та performance оптимізації
- Інтеграції та API дизайн
- Система трансформації персонажів

## Поточна архітектура
- Модульна система з Ci як центральним хабом взаємодії
- RESTful API на Flask з OpenAPI специфікацією
- Персонажні трансформації Ci залежно від контексту
- Інтеграція 7 зовнішніх API сервісів
- Docker контейнеризація для деплойменту

## Ключові принципи
- Ci як єдиний інтерфейс взаємодії
- Адаптивність персонажів до контексту
- Прозорість та безпека всіх операцій
- Ефективне використання часу користувача

Готовий працювати з архітектурними питаннями!
