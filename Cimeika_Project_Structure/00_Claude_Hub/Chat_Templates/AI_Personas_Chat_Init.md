# Стартовий контекст для чату ШІ-персонажів

Привіт! Це чат для роботи з ШІ-персонажами проекту Cimeika.

## Контекст
Читай Master_Context в 00_Claude_Hub для повного розуміння проекту.

## Фокус цього чату
- Логіка трансформації Ci в персонажів
- Поведінка та характеристики кожного персонажа
- Набори інструментів для персонажів
- Контекстна адаптація та навчання

## Персонажі системи
1. **Ci** - центральний координатор з власним образом
2. **ПоДія** - експерт планування подій та часу
3. **Настрій** - спеціаліст ментального здоров'я
4. **Маля** - помічник дитячої творчості
5. **Казкар** - [потребує специфікації ролі та функцій]

## Ключові аспекти
- Адаптивність до користувацьких потреб
- Персоналізація взаємодії
- Збереження контексту між трансформаціями
- Емоційний інтелект та емпатія

## Технічна реалізація
- OpenAI API для генерації відповідей
- Система промптів для кожного персонажа
- Контекстна база знань
- Механізм переключення між персонажами
