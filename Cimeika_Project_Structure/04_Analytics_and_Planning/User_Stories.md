# User Stories для Cimeika

## Персона: Сімейний користувач

### Як батько/мати, я хочу:

**Планування**
- Легко додавати сімейні події в календар
- Отримувати розумні рекомендації щодо планування
- Синхронізувати з Google Calendar
- Керувати подіями через мобільний телефон

**Настрій та здоров'я**
- Відстежувати свій емоційний стан
- Отримувати персоналізовані поради для покращення настрою
- Планувати активності з урахуванням самопочуття

**Дитяча творчість**
- Знаходити цікаві творчі завдання для дитини
- Зберігати малюнки та вироби дитини
- Ділитися досягненнями дитини з родичами

**Загальне**
- Мати єдиний інтерфейс для всіх потреб
- Отримувати персоналізовані рекомендації
- Використовувати голосові команди

## Персона: Дитина

### Як дитина, я хочу:

**Творчість**
- Отримувати цікаві завдання для малювання
- Грати в розвиваючі ігри
- Бачити свої роботи в красивій галереї

**Взаємодія**
- Розмовляти з веселим помічником
- Слухати цікаві історії
- Вчитися новому в ігровій формі

## Acceptance Criteria

### Epic: Ci-асистент
- [ ] Користувач може писати повідомлення в чаті
- [ ] Ci відповідає релевантно контексту
- [ ] Можлива трансформація в персонажів
- [ ] Зберігається історія розмов

### Epic: ПоДія
- [ ] Створення події через чат або форму
- [ ] Синхронізація з Google Calendar
- [ ] Telegram команди працюють
- [ ] Розумні рекомендації часу

### Epic: Настрій
- [ ] Фіксація настрою через інтерфейс
- [ ] ШІ генерує персоналізовані поради
- [ ] Вплив на планування інших активностей
- [ ] Тренди настрою відображаються

### Epic: Маля
- [ ] Творчі завдання доступні в інтерфейсі
- [ ] Завантаження робіт працює
- [ ] Файли зберігаються в Dropbox
- [ ] Галерея відображає творчість
