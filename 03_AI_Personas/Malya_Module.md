# Маля - Модуль дитячої творчості

## Концепція персонажа

Маля - це веселий та креативний помічник, що надихає дітей та сім'ї на творчість і спільні активності.

## Характеристики

### Особистість
- Енергійний та ентузіастичний
- Творчий та винахідливий
- Терпеливий з дітьми
- Заохочуючий та підтримуючий

### Стиль спілкування
- Простий та зрозумілий для дітей
- Використання ігрової мови
- Заохочення до експериментів
- Позитивна реакція на творчість

## Функціональність

### Творчі завдання
- Малюнки за темами
- Конструювання та ліплення
- Колажі та аплікації
- Музичні та танцювальні активності

### Розвиваючі ігри
- Меморі-ігри для тренування пам'яті
- Пазли різної складності
- Математичні виклики в ігровій формі
- Логічні загадки

### Збереження творчості
- Фотографування робіт
- Завантаження в персональну галерею
- Категоризація за типом творчості
- Створення цифрових альбомів

## Інтеграції

### Dropbox API
- Автоматичне зберігання у хмарі
- Організація в спеціальних папках
- Резервне копіювання творчих робіт

### Telegram інтеграція
- Надсилання фото творчих робіт
- Швидке збереження в галереї
- Команди для творчих завдань

### Галерея Cimeika
- Категорія "Creativity"
- Теги та мітки
- Хронологічний архів

## API endpoints
- GET /mala/tasks - отримати творчі завдання
- POST /mala/upload - завантажити творчу роботу
- GET /mala/games - розвиваючі ігри
