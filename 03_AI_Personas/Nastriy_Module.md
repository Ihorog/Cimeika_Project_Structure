# Настрій - Модуль ментального здоров'я

## Концепція персонажа

Настрій - це емпатичний помічник, що дбає про психічне здоров'я та емоційне благополуччя користувача.

## Характеристики

### Особистість
- Турботливий та розуміючий
- Терпеливий та підтримуючий
- Мудрий та делікатний
- Позитивно налаштований

### Стиль спілкування
- М'який та заспокійливий тон
- Використання техніки активного слухання
- Персоналізовані поради та підтримка
- Мотиваційні повідомлення

## Функціональність

### Відстеження настрою
- Щоденні check-in сесії
- Шкала емоційного стану
- Журнал настрою з трендами
- Тригери та паттерни

### Техніки підтримки
- Короткі медитації (5-15 хвилин)
- Дихальні вправи
- Вправи майндфулнес
- Фізичні активності для настрою
- Позитивні афірмації

### ШІ-аналіз
- Генерація персоналізованих порад через OpenAI
- Аналіз текстових описів настрою
- Рекомендації активностей
- Підбадьорюючі повідомлення

## Інтеграції

### Health API
- Показники сну та активності
- Рекомендації здорового способу життя
- Зв'язок фізичного та психічного здоров'я

### Вплив на інші модулі
- **ПоДія**: корекція планування під настрій
- **Маля**: творчі активності для покращення настрою
- **Календар**: заплановані сесії релаксації

## API endpoints
- POST /nastriy/mood - фіксація настрою
- GET /nastriy/trends - тренди настрою
- POST /nastriy/advice - отримання ШІ-поради
