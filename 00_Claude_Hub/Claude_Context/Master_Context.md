# Cimeika Master Context для Claude

## Проект
**Назва**: Cimeika
**Тип**: Інтегрована багатофункціональна платформа з ШІ-асистентом
**Стадія**: Етап побудови проекту
**Роль**: Архітектор/розробник

## Філософія
Єдиний розмовний інтерфейс Ci, що трансформується в персонажів:
- **Ci** - головний координатор з власним образом/логотипом
- **ПоДія** - планування подій (Google Calendar + Telegram)
- **Настрій** - ментальне здоров'я (OpenAI + Health API)
- **Маля** - дитяча творчість (Dropbox зберігання)
- **Казкар** - [потребує специфікації]

## Технічна архітектура
- **Backend**: Python + Flask + Gunicorn (порт 8000)
- **Frontend**: SPA (HTML/JavaScript) з динамічною навігацією
- **Deployment**: Docker контейнер з DevContainer підтримкою
- **API**: REST архітектура з OpenAPI специфікацією

## Зовнішні інтеграції
- OpenAI API (GPT для Ci-асистента)
- Google Calendar API (синхронізація подій)
- Telegram Bot API (мобільний доступ)
- Dropbox API (медіа зберігання)
- OpenWeatherMap API (погодні дані)
- FreeAstrologyAPI (гороскопи)
- Health API (показники здоров'я)

## Поточні пріоритети
1. Ci-трансформація - реалізація адаптивних персонажів
2. Розмовний інтерфейс - комплексний чат (текст/голос/файли)
3. Персонально-колективна логіка - адміністратор/організатор
4. Образна система - логотипи, стилі персонажів
5. Прогнозоване планування - ШІ-аналіз користувацьких прагнень

## Стиль роботи
- Технічні рішення з прикладами коду
- Архітектурне мислення з урахуванням взаємодії модулів
- Практичні кроки для впровадження
- Українська мова з технічною термінологією
